# 📘 Project Log Book
## Project Title: Students Marks and Performance Tracker

---

## Week 01: Group Establishment
**Date:** 28/07/2025 – 02/08/2025  

- Project group was formed and team members were finalized.
- Roles and responsibilities were assigned to each member.
- Initial discussion was conducted regarding academic requirements.
- Guide explained project guidelines, evaluation criteria, and documentation format.
- Planning for topic selection and feasibility study was initiated.

---

## Week 02: Topic Selection
**Date:** 04/08/2025 – 16/08/2025  

- Multiple academic management system ideas were discussed.
- Limitations of manual marks calculation were analyzed.
- Final topic selected: **Students Marks and Performance Tracker**.
- Defined project objectives and scope.
- Prepared problem statement and project proposal.
- Guide approval was obtained for the selected topic.

---

## Week 03: Requirement Analysis & System Overview
**Date:** 18/08/2025 – 23/08/2025  

- Detailed requirement analysis was carried out.
- Identified three main system roles:
  - **Admin**
  - **Teacher**
  - **Student**
- Functional requirements defined:
  - Admin login and user management
  - Teacher login and marks entry
  - Student login and performance viewing
- Non-functional requirements like security, usability, and accuracy were discussed.
- Overall system workflow was finalized.

---

## Week 04: System Architecture Design
**Date:** 28/08/2025 – 02/09/2025  

- Designed overall system architecture.
- Prepared Use Case Diagram for Admin, Teacher, and Student.
- Designed Data Flow Diagram (DFD) showing marks processing.
- Created Entity Relationship Diagram (ERD).
- Planned database tables for users, roles, subjects, marks, and results.
- Technology stack was finalized.

---

## Week 05: Phase 1 of Implementation (Login Modules)
**Date:** 03/09/2025 – 13/09/2025  

- Development environment was set up.
- Project folder structure was created.
- Implemented **Admin Login Module**.
- Implemented **Teacher Login Module**.
- Implemented **Student Login Module**.
- Role-based authentication was added.
- Login validation and error handling were tested.

---

## Week 06: Combined Design & Implementation
**Date:** 15/09/2025 – 20/09/2025  

- Database connectivity was established.
- Admin dashboard was developed.
- Admin features implemented:
  - Add teachers and students
  - Manage subjects
- Teacher dashboard was designed.
- Student dashboard structure was created.
- Integration between login modules and dashboards was completed.

---

## Week 07: Phase 2 of Implementation (Marks Management)
**Date:** 22/09/2025 – 04/10/2025  

- Teacher module for marks entry was implemented.
- Validation for marks input was added.
- Automatic calculation of total and percentage was implemented.
- Student module to view marks and grades was developed.
- Admin module to monitor overall performance was added.
- System was reviewed by guide.

---

## Week 08: Phase 3 of Implementation (Performance Tracking)
**Date:** 06/10/2025 – 18/10/2025  

- Performance analysis module was implemented.
- Grade calculation logic was added.
- Graphical representation of student performance was developed.
- Report generation feature was implemented.
- User interface was improved for better experience.
- Full system integration was completed.

---

## Week 09: System Testing
**Date:** 20/10/2025 – 01/11/2025  

- Unit testing was performed on Admin, Teacher, and Student modules.
- Integration testing ensured proper role-based access.
- Verified marks entry, calculation, and result display.
- Tested system using sample student data.
- Bugs and errors were fixed.
- Test cases and test results were documented.

---

## Week 10: Final Results & Analysis
**Date:** 03/11/2025 – 09/11/2025  

- Final system output was verified.
- Performance accuracy of marks calculation was analyzed.
- System objectives were successfully achieved.
- Results were compared with manual system.
- Screenshots of dashboards and reports were captured.
- Advantages and limitations were documented.

---

## Week 11: Final Report & Conclusion
**Date:** 10/11/2025 – 21/11/2025  

- Complete project documentation was prepared.
- Final project report was written.
- Project presentation (PPT) was prepared.
- Final demonstration was conducted before guide.
- Conclusion and future scope were documented.
- Project was successfully completed and submitted.
- Future enhancement ideas noted.
